## MotoCam v0.1.8

Release date: 2026-03-28

### Highlights

- Runtime permission audit flow added for camera, microphone, location, notifications, media access, and battery optimization guidance on Android.
- Device status integration added (battery %, battery temperature, thermal status) with live polling on the recording screen.
- Camera settings apply pipeline hardened to reduce black-preview/race behavior during resolution changes.
- Resolution handling moved to capability-aware routing with nearest-known-supported fallback per device/camera.
- Recording start and settings messaging improved to clearly report requested vs applied quality/FPS.
