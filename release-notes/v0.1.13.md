## MotoCam v0.1.13

Release date: 2026-07-07 (tag `v0.1.13`, commit `a33a583`)

No APK is attached to the v0.1.13 GitHub release.

### Upgrade notes / breaking changes

Read this before installing a v0.1.13 or later build over v0.1.12 or earlier.

- **New signing key, uninstall required.** Every published APK up to v0.1.12 was signed with an Android debug certificate (versionCode 1). Release builds are now signed with a dedicated release key and take their versionCode from `pubspec.yaml` (`1.0.1+13`). Android refuses to update across signing keys (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`), so v0.1.12 users must uninstall the old app first. Uninstalling removes the app's settings. Export any locked clips you want to keep before uninstalling.
- **Recordings moved to app-specific storage.** New recordings are written to the app's own external storage directory (`.../Android/data/com.example.motocam/files/MotoCam Recordings`, falling back to the app documents directory), and finished segments are exported as copies to `Movies/MotoCam/Recordings` through MediaStore. Ride History lists only the app-specific directory:
  - rides recorded by v0.1.11/v0.1.12 stay in `Movies/MotoCam/Recordings`; uninstalling does not delete them, but they no longer appear in Ride History;
  - recordings in app-specific storage are deleted when the app is uninstalled or its storage is cleared (the gallery copies remain).
- **Storage permissions removed.** `MANAGE_EXTERNAL_STORAGE`, `READ_MEDIA_VIDEO` and `READ_EXTERNAL_STORAGE` are no longer declared, the storage permission requests are gone, and the "Storage Permission" preflight check was replaced by "Media Write Access". `WRITE_EXTERNAL_STORAGE` is declared only up to API 28.
- **Backups disabled.** `android:allowBackup="false"` with explicit backup and data-extraction rules; recordings and settings are not included in Android cloud backup or device transfer.

### Summary

- Deep audit (`cd39097`): location-service stream leak fixed, `TelemetryData.fromJson` timestamp null-safety, Material 3 theme seeded with `colorSchemeSeed`, retention enforcement no longer blocks the UI with `statSync`, ride list no longer reads a provider in `initState`; shared path and integrity utilities extracted; dartdoc added; signature-protected internal broadcast permission for the Android bridges; iOS `processing` background mode and local-network keys removed.
- Performance and tests (`a33a583`): telemetry memory leak fixed, recording settings and start-preflight sheets extracted from `recording_screen.dart`, unit tests added for `RideRecord` and `TelemetryProvider`.
- Release tooling: release signing via `android/key.properties` or environment variables, `scripts/generate-keystore.ps1`, `scripts/release-security-precheck.ps1`, and a GitHub Actions CI workflow (analyze, precheck, tests).
- Application version in `pubspec.yaml` bumped to `1.0.1+13`; README points to `release-notes/`.
